# 충전량 표시 어플 기획서

> English: [Product plan](en/01_product_plan.md)

## 1. 제품 목표

Galaxy Z Fold8에서 충전기를 연결하면 사용자가 매번 시작 버튼을 누르지 않아도 배터리 충전 전력 추정값을 계산하여 상태바 알림에 표시한다. 기기의 AOD 알림 표시 설정이 허용되면 같은 알림의 충전 와트 문구가 AOD에도 표시될 수 있게 한다.

표시값의 정확한 이름은 **배터리 충전 전력(추정)** 이다. 충전기 또는 케이블이 공급하는 입력 전력과는 다를 수 있다. 휴대폰 자체 소비 전력과 충전 회로 손실이 반영되기 때문이다.

## 2. 대상 환경

| 항목 | 기준 |
|---|---|
| 우선 검증 기기 | Samsung Galaxy Z Fold8 |
| 플랫폼 | Android / Kotlin |
| 최소 호환 버전 | Android 14 (API 34) |
| 목표 호환 버전 | 구현 시점의 최신 안정 Android 버전까지 |
| 기본 표시 위치 | 상태바의 지속 알림 및 알림창 |
| AOD 표시 | Samsung AOD의 알림 표시 설정이 허용하는 범위 |
| 측정 대상 | 배터리 전압, 배터리 순 전류, 계산된 W |

## 3. 핵심 사용자 흐름

1. 사용자가 앱 설치 후 한 번 `자동 충전 모니터링`을 켠다.
2. 앱은 충전 여부를 감시할 수 있는 대기 상태를 유지한다.
3. 충전기가 연결되고 측정 전력이 1W 이상이면, 알림 제목 또는 본문을 `현재 18.6W 충전 중`처럼 갱신한다.
4. 사용자가 화면을 끄면, Samsung 설정에서 AOD 알림의 내용 표시가 켜져 있을 경우 해당 알림 문구가 AOD에 표시될 수 있다.
5. 충전이 끝나거나 전력이 1W 미만이면 충전 수치 표시는 멈추고 대기 상태로 바뀐다.
6. 사용자는 앱에서 자동 모니터링을 끄거나 진단 화면으로 측정 원시값을 확인할 수 있다.

## 4. 기능 범위

### 4.1 첫 번째 버전에 포함

- `BatteryManager` 및 배터리 상태 정보로 전압·전류 읽기
- 전압과 전류를 단위 변환하여 배터리 충전 전력 추정값 계산
- 기본 2초 간격 측정 및 값 안정화
- 1W 이상일 때 충전 전력 문구를 가진 지속 알림 갱신
- 자동 모니터링 켜기/끄기 설정
- 전압, 전류, 계산값, 충전 상태, 마지막 갱신 시각을 보여 주는 진단 화면
- 알림/AOD 표시 조건과 Samsung 설정 안내
- 단순한 배터리 윤곽선과 번개를 중심으로 한 현대적 디자인 시스템

### 4.2 첫 번째 버전에서 제외

- 삼성 순정 AOD 시계·레이아웃에 직접 위젯 또는 텍스트 삽입
- 충전기·케이블의 실제 입력 W, PPS 계약값, PD 프로토콜 값 보장
- 화면을 강제로 켜거나 잠금화면을 검은 화면 Activity로 덮는 방식
- 충전 속도 향상, 발열 제어, 충전 제한 제어
- 여러 제조사에서 동일한 수치를 보장하는 기능

## 5. 표시 및 배터리 정책

### 충전 중

- 조건: 충전 상태이며 안정화된 전력이 1W 이상
- 알림: `배터리 충전 전력 18.6W` 같은 짧은 문구
- 알림 소리·진동·팝업: 사용하지 않음
- 갱신: 기본 2초, 값 변화가 거의 없으면 불필요한 알림 재게시를 줄임

### 충전하지 않을 때

- 충전 W 문구는 표시하지 않는다.
- 대기 알림 문구는 `충전 모니터`로 한다. 작은 배터리·번개 아이콘을 사용하고, 소리·진동·팝업은 사용하지 않는다.
- 자동 감지를 신뢰성 있게 유지하려면 포그라운드 서비스용 조용한 대기 알림 또는 동등한 사용자 가시 상태가 필요할 수 있다.
- 대기 알림을 완전히 제거하면 서비스가 포그라운드 상태를 잃어 다음 충전 연결을 자동 감지하는 신뢰성이 낮아질 수 있다.

### AOD

- 앱은 일반 Android 알림만 제공한다.
- AOD에 알림 본문이 실제로 보이는지는 Fold8의 One UI 버전, 잠금화면 알림 설정, AOD 표시 설정, 사용자의 개인정보 표시 선택에 따라 달라진다.
- 따라서 AOD는 지원 기능이지만, 항상 숫자를 크게 표시한다고 보장하지 않는다.

## 6. 화면 및 디자인 방향

- 앱의 핵심 아이콘은 둥근 모서리의 단순한 배터리 윤곽선과 번개다. 복잡한 계기판, 입체 효과, 과도한 장식은 사용하지 않는다.
- 기본 색상은 무채색 기반에 하나의 선명한 강조색만 사용한다. 충전 중 상태는 현대적인 녹색 계열, 측정 불가·주의 상태는 노랑 또는 주황 계열로 구분한다.
- 큰 숫자와 넓은 여백을 우선한다. 대시보드 첫 화면은 현재 W, 충전 상태, 간단한 배터리 그래픽만 보여 준다.
- 설정과 진단 화면은 별도 화면으로 분리하여, 첫 화면이 구시대적인 제어판처럼 복잡해지지 않게 한다.
- 폴드형 화면은 접힌 상태의 좁은 화면과 펼친 상태의 넓은 화면을 모두 고려한다. 구현 단계에서 두 폭을 실제로 검증한다.

## 7. 기술 전제와 위험

| 항목 | 처리 원칙 |
|---|---|
| 전류 단위 | Android API 문서상 마이크로암페어(μA)로 처리하고, 임의의 1,000배 추정 보정은 하지 않는다. |
| 측정 미지원 | 값이 없거나 비정상이면 `측정 불가`로 표시하며 0W로 단정하지 않는다. |
| 값 흔들림 | 단일 순간값 대신 짧은 이동 평균 또는 중앙값으로 표시값을 안정화한다. |
| 자동 실행 | Android 버전별 백그라운드·포그라운드 서비스 제한을 실제 Fold8에서 검증한다. |
| 앱 종료 | 사용자가 시스템에서 실행 중인 앱을 중지하거나 제조사 절전 정책이 서비스를 종료할 수 있다. 복구 조건을 명확히 안내한다. |
| 배포 | Android 14 이상 포그라운드 서비스 유형과 Play 정책은 구현 직전에 최신 기준으로 다시 검토한다. |

## 8. 수용 기준

- 자동 모니터링을 켠 후 충전기 연결 시 별도 조작 없이 알림 값이 갱신된다.
- 충전 중에는 전압·전류·계산 W가 진단 화면과 알림에서 일관되게 확인된다.
- 충전 해제 후에는 충전 W 문구가 사라지고 대기 상태로 전환된다.
- 알림을 허용하지 않았거나 전류 측정이 지원되지 않으면 원인과 해결 방법을 앱에서 설명한다.
- Fold8에서 충전, 고속 충전, 화면 켜짐/꺼짐, 잠금, AOD, 충전 해제 상태를 실제로 검증한다.
- AOD에는 `기기 설정에 따라 표시`로 검증 결과를 기록하며, 보장 기능으로 표기하지 않는다.

## 9. 구현 전에 확정할 항목

- Play Store 배포 여부 또는 개인 설치 APK 여부
- 자동 모니터링의 부팅 후 재개 여부
- `1W 이상` 기준값을 사용자가 조정할 수 있게 할지 여부
- Fold8에서 사용할 One UI 버전 및 실제 AOD 설정 화면의 검증 결과
