# 충전 모니터 UI 설계 기준서

> English: [UI design guide](en/05_ui_design_guide.md)

> 목적: 현재 구현된 화면의 정보 구조와 시각 규칙을 기준선으로 고정한다. 이후 기능을 추가하거나 UI를 수정할 때 이 문서를 먼저 읽고, 새로운 화면 요소가 기존 흐름·색·밀도와 맞는지 판단한다.

## 1. 제품의 화면 성격

- 성격: 배터리 상태를 빠르게 읽고, 필요할 때 기록과 원시값을 확인하는 **조용한 계측 도구**다.
- 우선순위: 현재 상태 → 간단한 제어 → 시간별 기록 → 원시 진단.
- 느낌: 어두운 바탕, 넓은 여백, 한 가지 라임 강조색, 숫자가 주인공인 화면.
- 금지: 대시보드를 카드 모음·계기판·설정 패널처럼 과밀하게 만들지 않는다. 아이콘, 배지, 그림자, 탭, 필터는 기능 이해에 꼭 필요할 때만 추가한다.

## 2. 공통 시각 토큰

| 역할 | 값 | 사용 규칙 |
|---|---:|---|
| 기본 배경 | `Slate` `#071525` | 모든 주 화면의 기본 캔버스 |
| 차분한 그래프/빈 상태 표면 | `SlateSurface` `#0D2035` | 그래프와 빈 상태처럼 묶음이 필요한 곳에만 사용 |
| 강조 | `Lime` `#C7F31B` | 충전 상태, 선택 상태, 획득량, 충전 데이터의 핵심 수치 |
| 기본 글자 | `Ink` `#F2F5F7` | 제목과 현재 숫자 |
| 보조 글자 | `Muted` `#AAB7C5` | 설명, 단위, 시간, 부가 데이터 |
| 방전/비활성 그래프 | `GaugeTrack` `#40536A` | 방전 막대, 게이지의 남은 부분 |
| 구분선 | `Divider` `#30445A` | 설정 행과 정보 그룹 사이 |

### 타이포그래피와 여백

- 큰 현재 전력: `64sp` 숫자 + `28sp` 단위. 메인 게이지에서만 쓴다.
- 상태/완료/확인 문구: `42sp` 이하. 수치가 없을 때만 큰 크기로 쓴다.
- 화면 제목: `headlineMedium`, 섹션 제목: `headlineSmall`.
- 행 제목: `titleMedium`, 설명: `bodyMedium`, 그래프 축·보조 정보: `bodySmall`.
- 세로 화면의 기본 바깥 여백은 좌우 `28dp`, 상하 `16dp`다. 안전 영역을 항상 반영한다.
- 정보 그룹 사이 간격은 대체로 `22~28dp`, 행 내부는 `12~18dp`를 사용한다. 새 요소가 필요하면 먼저 기존 여백을 재사용한다.

## 3. 화면 흐름과 책임

```text
메인 대시보드
  ├─ 자동 모니터링 / 트렌드 기록 제어
  ├─ 트렌드 기록 설정 시트
  ├─ 트렌드 기록 화면
  │    ├─ 날짜 선택
  │    ├─ 배터리 흐름 막대그래프
  │    ├─ 충전 전력 변화 막대그래프
  │    └─ 오늘의 흐름 요약과 충전·방전 피크 기록
  └─ 상세 진단 화면
```

한 화면이 다른 화면의 역할을 가져오지 않는다. 메인은 실시간 값과 조작, 트렌드는 시간에 따른 비교, 상세 진단은 원시 측정값 확인에 집중한다.

## 4. 메인 대시보드

### 세로 화면

순서는 고정한다.

1. 배터리·번개 아이콘과 원형 게이지
2. 현재 W 또는 상태 문구
3. 충전/방전/완료 등 상태 문구
4. `배터리 % · 전압 · 전류` 한 줄 요약
5. 구분선
6. 자동 모니터링 설정 행
7. 구분선
8. 트렌드 기록 설정 행과 기록 주기 진입 문구
9. 구분선
10. `트렌드 기록 ›`, `상세 진단 ›` 이동 행

메인에는 과거 피크·시간별 기록·그래프 요약을 추가하지 않는다. 이 정보는 트렌드 화면의 역할이다.

### 가로/펼친 화면

- 왼쪽: 게이지와 원시값 한 줄 요약.
- 오른쪽: 설정 행과 이동 행.
- 두 열은 같은 중요도를 가지며, 가로 화면에서도 제어가 화면 하단에 몰리지 않게 한다.

## 5. 상세 진단

- 목적: 표시값의 근거와 배터리의 현재 상태를 빠르게 확인한다.
- 순서: `실시간 측정`(배터리 전력·전압·현재/평균 전류·충전량(SOC)·마지막 측정) → `배터리 상태`(온도·시스템 상태·건강도(SOH)·사이클·남은 전하/에너지·완충 예상) → `연결 정보`(전원 종류·배터리 유형·충전 상태·감지 상태) → 면책 문구.
- SOC는 현재 충전량이고, SOH는 새 배터리 대비 건강도라는 점을 명확히 분리한다. 공개 Android API가 SOH 수치를 제공하지 않으면 추정하지 않고 `시스템 미제공`으로 표시한다.
- 화면에 진입하거나 `새로고침`을 누르면 자동 모니터링 상태와 독립적으로 시스템 값을 새로 읽는다.
- 모든 항목은 `왼쪽 레이블 / 오른쪽 값` 한 행이며, 행 사이에는 구분선 하나만 둔다. 화면이 길어질 수 있으므로 세로 스크롤만 허용한다.
- 그래프·토글·추가 설명 카드는 넣지 않는다. 이 화면은 측정값을 비교하는 표다.

## 6. 트렌드 기록

### 화면 순서

1. `트렌드 기록` 제목
2. 최근 날짜 줄: 탭 선택, 좌우 스와이프, 과거 날짜일 때 `오늘` 복귀
3. `배터리 흐름`
4. 00:00~24:00 고정 시간축의 배터리 잔량 막대그래프
5. 그래프 터치/가로 드래그로 고정되는 시간 커서 정보
6. `충전 전력 변화`
7. 00:00~24:00 고정 시간축의 충전·방전 전력 막대그래프
8. 기록 주기 평균 안내
9. `오늘의 흐름` 네 항목 요약
10. 구분선 기반의 `충전 피크`·`방전 피크` 기록 행

### 그래프 규칙

- 그래프는 선을 이어 추정하지 않는다. 기록이 있는 시각에만 세로 막대를 그린다.
- 하루의 전체 폭은 항상 `00 · 06 · 12 · 18 · 24` 고정이다. 데이터가 적어도 막대를 늘려 채우지 않는다.
- 충전 막대는 라임, 방전 막대는 `GaugeTrack`을 사용한다.
- 선택 커서는 라임 세로선과 점으로 두 그래프에 같은 시간 위치를 표시한다.
- 빈 시간은 값을 추정하지 않고 `기록 없음`으로 보여 준다.
- 1분 또는 5분 설정에 따라 기록 주기가 달라도, 과거 데이터를 억지로 보간하지 않는다.

### 오늘의 흐름 요약

- 기본 항목은 `충전 횟수 / 획득 % / 방전 % / 전력 피크`다.
- 한 줄 네 열을 유지한다. 각 항목은 레이블 위, 값 아래의 짧은 구조를 지킨다.
- 강조가 필요한 획득량과 충전 관련 수치만 라임을 사용한다. 방전 수치는 흰색 또는 보조색을 사용한다.

### 피크 기록 규칙

- 충전 피크·방전 피크와 그 시각·당시 배터리 잔량은 **트렌드 기록 화면에만** 둔다.
- 위치는 두 그래프 아래의 `오늘의 흐름` 네 열 요약 바로 아래다.
- 메인 대시보드·상세 진단에는 중복하지 않는다.
- 표현은 기존 구분선 기반의 두 개 정보 행 또는 두 열 밴드 중 하나로 제한한다. 새 카드, 새 아이콘, 새 그래프는 만들지 않는다.
- 각 방향은 `피크 W`, `HH:mm`, `배터리 %`만 기록한다. 피크가 없으면 `—`와 시간·잔량 없음으로 통일한다.
- 수치는 순간 피크가 아니라 선택된 기록 주기의 평균값 중 최대값이므로, 그래프 안내와 같은 `기록 주기 평균 기준` 의미를 유지한다.

## 7. 설정 시트

- 트렌드 기록 주기 선택은 메인에서 진입하는 하단 시트만 사용한다.
- 시트에는 제목, 표준 5분 평균, 정밀 1분 평균만 둔다.
- 각 선택지는 라디오 버튼, 제목, 한 줄 설명의 세 요소로 구성한다.
- 시트 안에 별도 저장 버튼을 넣지 않는다. 항목을 선택하면 즉시 적용하고 시트를 닫는다.

## 8. 외부 표시 영역

- 지속 알림: 제목은 앱 이름, 본문은 현재 W와 충전/방전 상태를 짧게 표시한다.
- 상태바: 단색 소형 플러그 실루엣만 사용한다. 숫자·복잡한 배터리 외곽·대형 아이콘은 넣지 않는다.
- AOD: 앱이 별도 위젯을 구성하지 않는다. 시스템이 노출하는 지속 알림의 제목/본문만 기대한다.

## 9. 변경 전 확인 질문

새 UI를 만들기 전에 아래를 순서대로 확인한다.

1. 이 정보는 메인·트렌드·상세 진단 중 어느 화면의 책임인가?
2. 현재 화면의 구분선·행·그래프 중 하나를 확장하면 충분한가?
3. 새 카드, 아이콘, 탭, 색이 정말 필요한가?
4. 세로 폴드, 가로/펼친 폴드, 긴 번역 문자열에서도 여백과 줄바꿈이 유지되는가?
5. 기록값이라면 시간축·기록 주기·평균이라는 사실을 사용자가 오해하지 않는가?

기본 배경 Slate #071525, 강조 Lime #C7F31B, 보조 글자 Muted #AAB7C5, 구분선 Divider #30445A를 사용한다.

## 11. 기준서 검증 범위

- 이 문서는 현재 Compose 구현과 기존 Fold8 화면 확인 기록을 기준으로 작성했다.
- 화면의 실제 시각적 일치 여부는 다음 UI 기능 수정 때 Fold8 세로·가로 화면에서 다시 확인한다.
- 이 문서는 UI 코드 변경이 아니라, 이후 변경의 설계·리뷰 기준이다.
