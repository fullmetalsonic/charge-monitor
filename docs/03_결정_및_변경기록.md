## 2026-08-20 - Fold8 실기기 피드백 반영

- 구분: 변경
- 내용: 배터리 API가 `FULL` 상태이고 전류가 거의 0 또는 음수인 만충 상황을 `충전 완료`로 별도 표시한다. 지속 알림은 상태별 문구와 잠금화면 공개 본문을 사용한다. 대시보드는 시스템 안전영역을 반영해 하단 탐색 바와 겹치지 않게 조정한다.
- 근거 또는 확인 방법: Fold8 스크린샷에서 100%, 4.45V, -0.01A가 확인됐고 기존 상태 분류는 이를 `충전 대기 중`으로 처리했다. AOD 실제 표시 방식은 One UI 설정과 실기기 재검증이 필요하다.
- 영향 파일: 배터리 데이터 소스, 상태 분류, 알림, 대시보드, 단위 테스트
- 상태: 완료 (`v0.1.1` 비공개 Release), AOD 실기기 검증 필요

## 2026-08-20 - 방전 및 충전 시작 상태 표시

- 구분: 변경
- 내용: 충전기가 분리된 상태는 `방전 중`으로 표시한다. 충전 직후 전류값이 잠시 없을 때는 처음 두 번의 측정 동안 `충전 상태 확인 중`을 표시하고, 이후에도 값이 없을 때만 `전류 측정 불가`로 표시한다.
- 근거 또는 확인 방법: 지속 알림은 서비스 시작 직후 만들어지고 전류는 2초 간격으로 갱신된다. Fold8에서 잠금화면 AOD가 최초 알림만 표시하는 경우 혼동을 줄이기 위해 초기 상태를 분리한다.
- 영향 파일: 상태 모델·분류·안정화·서비스·알림·대시보드·단위 테스트
- 상태: 완료 (`v0.1.2` 비공개 Release), AOD 실기기 검증 필요
